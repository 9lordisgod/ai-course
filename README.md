# SI Academy · Super Intelligence Academy

**Open-source K–12 AI literacy platform aligned with Canada's National AI Literacy Initiative and provincial curricula — with Khan-style mastery, a Teacher Hub and studio-quality voice-over powered by ElevenLabs.**

## Features

| Feature | Details |
|---|---|
| **4 learning paths · 8 modules · 12 lessons** | Foundations → Critical Thinking → Ethics & Responsibility → Futures & Careers. How AI works · Generative AI & cognitive offloading · Bias, deepfakes & misinformation · Privacy & data · Academic integrity · Indigenous data sovereignty (OCAP®) · Responsible classroom use · Future-ready careers |
| **Mastery system** | Khan-style mastery points per lesson (Not started → Attempted → Familiar → Proficient → Mastered), module mastery bars, practice quizzes with instant feedback, printable certificate |
| **AI voice-over** | Every lesson narrated by natural ElevenLabs voices (`eleven_multilingual_v2`); server-side proxy, per-lesson cache, automatic browser-speech fallback |
| **Global search** | Instant search across lessons, modules and provincial policies |
| **Course catalog** | Sidebar filters by grade band (K–5 / 6–8 / 9–12) and curriculum area; level badges (Beginner / Intermediate / Advanced); "Start here" guidance |
| **Teacher Hub** | Tabbed dashboard: traffic-light (🟢🟡🔴) AI-use policy generator, student disclosure template, module planner with total class time, official resources |
| **Parents** | Plain-language FAQ on Canadian school expectations + recommended modules for younger learners |
| **Provincial Policy Explorer** | B.C., New Brunswick, Ontario, Alberta, Manitoba, Quebec + federal programs, with status badges |
| **Dark mode & accessibility** | System-aware dark theme, keyboard navigation, skip link, reduced-motion support, print styles |
| **Pitch deck** | `/pitch/` HTML deck + [`.pptx`](pitch/SI-Academy-Pitch-Deck.pptx) + [Markdown](pitch/pitch-deck.md), regenerated by `npm run deck` |
| **Privacy-first** | No accounts, no tracking; progress and quiz results stay in the browser (`localStorage`) |

## Design

The UI borrows from two references: **Khan Academy** (unit/lesson sidebars, mastery points and levels, breadcrumbs, practice with feedback) and **Plan B Network** (IBM Plex typography, black/white with an orange `#ff5c00` accent, pill buttons, warm off-white sections, 16 px cards with hairline borders, level badges). Everything is hand-written CSS with design tokens in `public/assets/styles.css`; icons are an inline SVG set in `app.js`.

**Logo:** an abstract 8×8 pixel-art "S" whose pixels brighten along the diagonal until they reach a single blue spark — the *i* in SI, intelligence emerging from the first pixel. It lives in `public/assets/favicon.svg` and as the `LOGO` constant in `app.js` (hover the brand to see it spark).

## Quick start

```bash
git clone https://github.com/9lordisgod/ai-course.git
cd ai-course
npm install
cp .env.example .env        # add your ELEVENLABS_API_KEY
npm start                   # http://localhost:3000
```

Without an ElevenLabs key the site still works — the **Listen** button falls back to the browser's built-in speech synthesis.

### Get an ElevenLabs key
1. Sign up at <https://elevenlabs.io> (free tier: 10,000 credits/month).
2. Create a key at *Settings → API Keys* and set `ELEVENLABS_API_KEY` in `.env`.
3. Optional: pick a voice via `GET /api/voices` and set `ELEVENLABS_VOICE_EN`.

## Deploy

**GitHub Pages (static, included):** every push to `main` runs [`pages.yml`](.github/workflows/pages.yml), which tests, builds the deck and publishes `public/` + `pitch/` + `docs/` to <https://9lordisgod.github.io/ai-course/>. Pages has no server, so narration uses the browser voice — unless you set a repository variable `TTS_API_BASE` pointing at a hosted copy of the API (below); the workflow injects it into `window.SI_CONFIG.apiBase`.

**Node host with ElevenLabs (Render, Railway, Fly, VPS):** `npm ci && npm start`, set `PORT`, `ELEVENLABS_API_KEY` and optionally `ALLOWED_ORIGIN=https://9lordisgod.github.io` to let the Pages front-end call `/api/tts`.

**Serverless:** `api/*.js` are ready-made serverless functions (Vercel-compatible) that wrap `server/tts.js`; `public/` is served statically via `vercel.json`.

## API

| Endpoint | Description |
|---|---|
| `POST /api/tts` `{ "text": "..." }` | Returns `audio/mpeg` (English voice). 503 + `{ fallback: "browser-speech" }` when no key. Rate-limited 30 req/min/IP. |
| `GET /api/voices` | Lists voices available to your ElevenLabs account |
| `GET /api/health` | `{ ok, tts, model }` |

## Mastery rules

| Level | Points | How to reach it |
|---|---|---|
| Not started | 0 | — |
| Attempted | 20 | Practice quiz below 50 % |
| Familiar | 50 | Quiz ≥ 50 %, or lesson marked complete without a quiz |
| Proficient | 80 | Quiz 100 %, or complete + quiz ≥ 50 % |
| Mastered | 100 | Lesson complete **and** quiz 100 % |

Module mastery = sum of lesson points / (lessons × 100). Everything is stored locally under `progress` and `quiz`.

## Adding content

Edit `public/data/courses.json`. Each module needs `icon`, `path`, `level`, `grades`, `curriculum`, `title` and `summary`; each lesson needs `title`, `body`, `activity` strings plus a `quiz` array (`q`, `options`, `answer`). UI copy lives in `public/data/i18n.json`. Run `npm test` — it verifies every lesson is complete and every quiz answer index is valid.
